# AI-Powered Customer Complaint Management System

An AI-powered Customer Complaint Management System designed for the pharmaceutical manufacturing industry.

## Features

* Submit customer complaints through the frontend
* AI-powered complaint analysis
* Complaint classification and severity assessment
* Root cause analysis
* AI-generated recommended actions
* User review of AI-generated results
* Store complaint data in Neon Database

## Workflow

```text
User Input
    ↓
Frontend
    ↓
Backend API
    ↓
AI Complaint Analysis
    ↓
User Review
    ↓
Neon Database
```

## Tech Stack

* Frontend: React
* Backend: Python, FastAPI
* AI: LLM-based complaint analysis
* Database: Neon PostgreSQL
